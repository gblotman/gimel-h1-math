# gimel-h1-math

משחק web בעברית להכנה למבחן במתמטיקה בכיתה ג׳: מבנה עשרוני, סדרות, חיבור וחיסור, כפל וחילוק, סימני התחלקות, שאלות מילוליות וזוויות.

- קובץ יחיד (`index.html`), בלי תלויות – פשוט פותחים בדפדפן.
- 10 שאלות אקראיות בכל נושא בכל סיבוב, עם 3 רמזים מדורגים לכל שאלה.
- עובד במובייל, בטאבלט ובדסקטופ. ההתקדמות נשמרת ב-localStorage.
